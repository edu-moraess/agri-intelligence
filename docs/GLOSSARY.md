# Glossário

- **Observação:** evidência registrada diretamente por um sensor ou anotação.
- **Predição:** saída de um modelo, com método e confiança.
- **Medição derivada:** valor calculado a partir de observações/predições e uma transformação declarada.
- **Gap observado:** ausência visual compatível com uma lacuna; não é falha agronômica confirmada.
- **GSD:** ground sampling distance, resolução no terreno quando validamente conhecida.
- **CRS:** sistema de referência de coordenadas.
