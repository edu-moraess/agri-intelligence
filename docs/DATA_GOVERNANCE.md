# Governança de dados

Todo dataset deve registrar origem, licença, versão, checksum, campanha, sensor, cultura, localidade, resolução, anotações, splits e limitações. O original deve ser preservado e transformações devem ser reproduzíveis.

O MSDD é apenas candidato de benchmark. Nesta fase ele não é baixado nem declarado adotado. Antes de qualquer uso, sua fonte, licença, documentação, classes, qualidade, relações com vídeo e risco de leakage devem ser auditados.
