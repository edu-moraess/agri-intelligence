# Metodologia científica

Não são permitidas métricas, conclusões agronômicas ou comparações sem dados e protocolo reproduzíveis. Confiança do modelo não equivale a certeza de medição.

Avaliações futuras devem separar campanhas, campos e datas quando aplicável e declarar precisão, recall, F1, AP, erro de contagem, erro de localização, erro de espaçamento, erro populacional, calibração e generalização somente quando efetivamente calculados.
