# Protocolo de validação

A Fase 0 usa apenas verificações determinísticas: estrutura esperada, importação do pacote, compilação de Python, ausência de arquivos proibidos e testes de contratos.

`PASS` exige que todas as verificações obrigatórias tenham sido executadas e aprovadas. `PASS_WITH_WARNINGS` é reservado a limitações documentadas sem falha obrigatória. `FAIL` cobre falha ou verificação não executada.
