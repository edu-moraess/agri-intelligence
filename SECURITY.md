# Segurança

Não reporte credenciais, dados pessoais ou datasets proprietários em issues públicas. Envie vulnerabilidades de forma privada aos mantenedores do projeto.

Regras da fundação:

- Segredos devem permanecer fora do Git e em arquivos locais ignorados.
- Dependências novas exigem justificativa e revisão de licença/proveniência.
- Scripts não devem baixar dados ou executar código remoto implicitamente.
- Resultados científicos devem declarar dados, divisão, método, incerteza e limitações.
